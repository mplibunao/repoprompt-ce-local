#### A. The `tf1` contribution codec

- Decision: `TerraformCodeMapGraphNames.swift` is the only `tf1` codec. It encodes with the artifact container's JSON settings (`.sortedKeys`, `.withoutEscapingSlashes`), and a name is valid only when its tag and arity are known and decoding and re-encoding give the same bytes. The source-kind component uses the raw values of `TerraformModuleSourceKind`. Every Terraform contribution must hold `["folder"]`, at most one `call` per label, and a `call` for every `call-duplicate`. Source: approved plan for the format; the implementing agent's judgment for the source-kind strings and the checks across tuples.
- Decision: the shared contribution initializer doesn't apply NFC to a whole Terraform token, because JSON escaping comes first and NFC can then join an escape's letter with a following combining mark, as in `\n` followed by U+0303. The codec normalizes each component instead. Contribution names are deduplicated by their bytes for every language, so a malformed token can't be merged into a canonically equal valid one and escape validation. Legacy names are already NFC, so their output doesn't change. Source: review finding, round 1, for the NFC fix; the implementing agent's judgment for byte deduplication.
- Decision: the artifact container now rejects a Terraform key with outcome `readyNoSymbols`, on encode and decode, so `ready` with an empty payload is the only form of an empty Terraform file. This reverses PR 2's choice to accept it: every producer built an empty contribution for that outcome, which the new folder-membership check rejects. Source: review finding, round 1.
- Decision: a declaration with an empty label adds no graph name. Terraform rejects an empty variable, output, module call, or resource or data type or name, so no valid configuration loses a link, and the outline still shows the declaration. Source: the implementing agent's judgment; the orchestrator declined round 2's finding that asked to keep their tuples.
- Decision: the plan's `testAllContributionProducersAgreeAcrossColdAndWarmPaths` is `testArtifactContributionMatchesVerifiedCleanRecordAndDecodedEnvelope`, which drives artifact construction, `verifiedClean`, and the decoded envelope. The binding engine's `graphIndexEntry` overloads are private and its candidates come only from catalog pages that drop unsupported extensions, and overlay adoption needs a real Git repository, an artifact-store lease, and a registered root. PR 4's planned real-store test, `testTerraformManifestLifecycleProducesIdenticalGraph`, drives those paths once `.tf` is registered. Source: review finding, round 1, and orchestrator judgment.
- Evidence: the review loop ran `context_builder` (review) from a session bound to this worktree, on one chat for three rounds. Round 1 raised the whole-token NFC bug, the `readyNoSymbols` mismatch, and the producer test's overstated scope.
