## 3. Bundled Codex 0.164.0 to 0.170.0

- Decision: the rotation gives issue #126 the concrete reason it asks for, a model that the bundled runtime can't use, so the pull request resolves it. Source: approved plan.
- Evidence: on 2026-11-18, three Codex model caches signed in to the same ChatGPT account showed the gating. Production's Codex home (`client_version` 0.159.0, fetched 07:58Z and again 12:15Z) and the debug app's Codex home on PR #357's build (`client_version` 0.164.0, fetched 07:56Z) listed neither 6.2 model. A local Codex CLI 0.166.0 (fetched 11:59Z) listed both. 0.165.0 wasn't tried.
- Decision: bundle exactly Codex 0.170.0, the version upstream PR 1734 pins, instead of 0.166.0, the lowest version observed receiving the 6.2 models. Both add the `codex-exec-server` helper, so the lower version saves no work and would mean a second rotation. Source: approved plan.
- Decision: the package metadata gains a required `execServer` field equal to `bin/codex-exec-server`, the runtime refuses to launch when that executable is missing, and the helper is signed by OpenAI with no entitlements. The guardrails now pin an exact three-path primary policy: V8 for `bin/codex` and `bin/codex-code-mode-host`, none for the helper. Source: approved plan.
- Decision: to get the candidate tool past its layout gate for an added Mach-O, the verifier's layout and signing constants changed first, and the 0.164.0 manifest briefly carried placeholder helper entries while the official candidate ran. Editing only the manifest, as the Zsh removal in PR #357 did, can't admit a new primary executable, because the verifier pins those constants. `docs/releasing.md` now describes the procedure. Source: implementing agent's judgment, accepted.
- Decision: `docs/releasing.md` names bundled 0.159.0 as the production rollback, because 0.164.0 was never promoted, and says that returning to 0.159.0 means reverting both rotations. Source: approved plan.
- Decision: the manifest loader rejects duplicate signature policies, so a second, V8-granting policy for the helper can't slip past the guardrail. Source: review finding.
- Evidence: against the unchanged 0.164.0 manifest, the official `rust-v0.170.0` candidate refused only `extra=['bin/codex-exec-server']`, and then passed in official online mode. Both archives matched the official checksum file. Each target goes from 49 to 50 entries and from 29 to 30 Mach-Os. The parameters RepoPrompt sends to `initialize`, `thread/start`, `thread/resume`, `turn/start`, and `turn/steer`, and the `model/list` response it reads, are byte-identical in the generated schemas.
