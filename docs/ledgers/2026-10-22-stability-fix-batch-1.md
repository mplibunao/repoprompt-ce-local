## 3. #248: skip an unchanged `prompt set`, after DEBUG memory instrumentation

- Decision: the DEBUG instrumentation is the first commit and is the memory baseline (`main` plus that commit). It adds `domainRead.registration` and `workspaceSave.domain.preSaveDecode` timed events, per-event totals, and decode-cache counters to `restore_perf_metrics`. Registration timing sits inside `DomainWorkspaceAuthorityClient.registerForRead`, so it covers every caller. Source: plan, with the placement chosen by the engineer.
- Decision: the fix sits in the caller, `commitPromptContextToUI`. It skips the stored write when the text is unchanged but still syncs the active editor, and leaves `updateComposeTabStoredOnly` and `bumpStateVersion` unchanged for their other callers. Source: plan.
- Decision: the PR says `Part of #248`, because registering only the changed tabs, the issue's main criterion, stays open on the issue. Labels are `bug` and `area:mcp`. Source: orchestrator judgment, the same rule as #233.
- Evidence: the new test, an unchanged `prompt set` on a background tab leaving the state version alone, fails on today's code (22 → 23) and passes with the fix. Debug app on the profile's `rp` workspace (919 tabs, 5.8 MB): an unchanged `prompt set` caused no registration, and a changed one caused exactly one (153.5 ms, almost all of it encoding in the app). Pre-save decodes took 56.5 to 82.9 ms, and both missed the decode cache. The branch merges cleanly with #176's branch.
- Review: no blockers. Accepted: record the smoke result and the commands; add a test that an unchanged `prompt set` still replaces an unsaved edit in the active editor; name `dateModified` among the behavior changes; tighten the instrumentation wording. The cleanup pass made no changes.
- Evidence: the second test, an unchanged `prompt set` still replacing an unsaved edit in the active editor, fails when the editor sync is skipped and passes with the fix. `pr-ready` passed on its first run: 1,891 root tests, 0 failures, plus the `RepoPrompt` build. The branch merges cleanly with PR #259's head.
