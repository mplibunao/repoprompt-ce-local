## 4. Debug-app validation, review, refactor, `pr-ready`, pull request

- Evidence: debug app built from `ebda99000` with `make dev-smoke-launch` after confirming through `rpce-cli-debug` that it had no running or waiting agent session and no provider work in flight. The first smoke attempt failed while window 1 restored a large saved workspace; `make dev-smoke` against the running app then passed.
- Evidence: a Claude Code (Sonnet Latest) session showed a context ring of 7 after one turn (69,721 tokens of a 1M window). After `/compact` the raw Claude events had a manual `compact_boundary` (`pre_tokens` 69,736) and the ring showed `?` with "Pending". - Decision: the reopen check used a debug-app relaunch, because closing an MCP-started session's tab deletes that session, so a history reopen wasn't possible for it. Source: orchestrator judgment after observing the deletion.
- Evidence: `compact_boundary` also carries `post_tokens` (7,001 and 6,685 in these runs), well below the next measured occupancy, which supports waiting for a real reading instead of using it.

(1) shares a root with the slot-mapping limitation in item 3 (capacity attributed to the current selection instead of the model that reported it), so both go to one follow-up; fixing (2) would add persisted state for a display difference. Source: orchestrator judgment.
